# 个人名片页

一个纯 HTML + CSS 的单文件个人主页：居中的卡片式名片，包含头像、名字、签名、两段自我介绍和一组胶囊链接，内置三种主题色一键切换。

## 技术栈

- **HTML** —— 语义化标签（`header` / `nav` / `section` / `footer`），页面结构自描述
- **CSS** —— flex 居中布局、`linear-gradient` 双渐变（页面背景 + 头像）、衬线/无衬线字体搭配、CSS 变量驱动主题
- **JavaScript** —— 仅 3 行：切换 `data-theme` 属性实现全局换色

无框架、无依赖、无构建步骤。

## 运行方式

方式一：直接双击 `名片页.html`，用浏览器打开即可（文件自包含，不依赖同目录其他文件）。

方式二：部署为静态页面（GitHub Pages / Vercel / Netlify 均可，任选一个平台上传本文件即可）。

## 功能特性

- 主题换色：页面底部「换色」按钮循环切换三套配色，头像渐变与按钮描边联动变化
- 响应式：窄屏下卡片自动撑满宽度
- 单文件：CSS / JS 全部内联，复制走即用
